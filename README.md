## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **LUT Library** | Organize LUT files by type, manufacturer and color style |
| **Grade Notes** | Document color grading notes and LUT selections per project |
| **Pipeline Config** | Plan your color pipeline setup with input and output LUT order |
| **Style Reference** | Tag LUTs by mood and look for fast creative selection |
